# Contributing

Thanks for helping. This repo is generated from a private source: the published files are rebuilt from it for every release.

- **Pull requests are welcome.** We port accepted changes into the source by hand, so they ship in the next release, and credit you in the changelog.
- **Issues:** bugs, accessibility problems and rough edges in any component. A minimal reproduction helps a lot.
- **Before you open a PR:** run `npm run check`. It installs every item into a fresh Next.js app and type-checks it.

Please keep changes focused: one component or fix per PR.
